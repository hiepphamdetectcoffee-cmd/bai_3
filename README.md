# Android Checkbox Demo

A sophisticated React application that demonstrates an Android-style user interface with interactive checkboxes and custom Toast notifications.

## Features

- **Android System UI Simulation**: Realistic device frame, status bar, and home indicator.
- **Interactive Checkboxes**: Smooth toggle animations using `motion`.
- **Custom Toast Notifications**: Android-style feedback messages that appear when "KIỂM TRA" is clicked.
- **Elegant Dark Theme**: A modern, high-contrast dark aesthetic with blue accent colors.

## Technologies Used

- **React 19**: Modern functional components and hooks.
- **Tailwind CSS 4**: Utility-first styling with the latest features.
- **Motion**: Fluid animations and transitions.
- **Lucide React**: Clean and consistent icons.

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```
3. Build for production:
   ```bash
   npm run build
   ```
